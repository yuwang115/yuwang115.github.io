# yuwang.blog

Source for [yuwang.blog](https://yuwang.blog/), Yu Wang's academic website and interactive glaciology tools.

## Highlights

- [3D Antarctica: Interactive Antarctica & Greenland Explorer](https://yuwang.blog/tools/3d-antarctica/)
- [Live explorer runtime](https://yuwang.blog/tools/antarctica-bedmachine-3d.html)
- [Research tools index](https://yuwang.blog/tools/)
- [Publications](https://yuwang.blog/publication/)

## Local development

```bash
hugo server
```

Build a production site with:

```bash
hugo --minify --baseURL https://yuwang.blog/
```

- Hugo
